IMAGES FOLDER
box.png (right here in images/) is the picture box on the home tab. Any picture, name it box.png.
One subfolder per section (images/identity, images/creative, ...). Put pictures for that section there, then
then type the FILE NAME in that section's data file, e.g.  cat-drawing.png
Year pages use images/years/<year>/ (e.g. images/years/2026/).
Tips: .jpg/.png/.webp. Keep each under ~1.5 MB so the site stays snappy. No spaces in file names.
